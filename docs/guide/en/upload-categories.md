## Ebook

For **Ebook** (Livres, BDs, Comics, Manga, Presse, Audio, Partitions, Revues & Manuels), the subcategory defaults to BDs for CBR/CBZ or page-image folders, Audio for MP3/M4A/M4B/FLAC and Livres otherwise. Refusals: no file, archives (RAR/ZIP/7z), no accepted format (PDF, EPUB, MOBI, DjVu, CBR, CBZ, JPG/PNG, audiobooks). Warnings: French only, no duplicates, no more than two formats of a book, whole volumes in a BD/Comics/Manga pack (every volume for a BD). The name is `Titre.Auteur.FRENCH.EPUB-NOTAG` (title and author guessed from `Auteur - Titre`; the Source field is the team tag; a pack adds `[T01.a.T07]`; press is `Titre.Date.FRENCH.PDF-NOTAG`), and the file format and French language options are pre-filled. An audiobook under 64 kbps (read from its tags) is refused. Open c411's upload page, load the Draft, add the image the rules ask for, and publish it there. See [ADR-0011](../../adr/0011-uploads-start-as-c411-drafts.md) and the [rules summary](../../research/upload-rules.md).

## Audio

For **Audio** (Karaoké, Musique, Podcast Radio, Samples), the subcategory defaults to Musique. TorrentLinker reads each file's tags (artist, album, year, titles, durations, codec, bitrate, sample rate, bit depth) with [mutagen](https://mutagen.readthedocs.io), off the GUI thread, when you select an item; the checks that need them appear a moment later. Refusals: no audio file, archives, formats c411 does not list (APE, Opus, AAC files…; FLAC, ALAC, WAV, WV, AIF, MP3, M4A, OGG, WMA and ISO are accepted), MP3 under 320 kbps constant bitrate (VBR accepted) and AAC under 256 (128 for podcasts and radio), a one-file album without a `.cue`, and formats or bitrates mixed in one album. Warnings: no transcodes, singles only from 20 minutes, discographies only for inactive artists, and for a CD-Rip (lossless 16 bit 44.1 kHz with a `.cue` or `.log`) what is missing among `cover.jpg` (500×500 or more), the `.cue` and the EAC `.log`, plus the catalogue number and Discogs or MusicBrainz link the description must give. The name is built from the tags and editable: music `Daft.Punk.Discovery.2001.FLAC.16bit.44.1kHz-NOTAG` (`CD-Rip` after the year for a CD-Rip, `MP3.320kbps` for a lossy one), podcast `Emission.2024.05.12.INTEGRALE.MP3.128kbps-NOTAG`, samples `Nom.2023.wav.1411kbps`. The NFO states artist, album, year, source, codec, bitrate or bit depth, sample rate, track count, size and the tracklist with durations; the format, source (CD) and type (Album or Discographie) options are pre-filled.

## Films and videos

For **Films & Vidéos** (Animation, Animation Série, Concert, Documentaire, Série Documentaire, Émission TV, Film, Série TV, Spectacle, Sport, Vidéo-clips, Collection), the subcategory defaults to Film, or Série TV when the name has a season or episode. Each video is read with [MediaInfo](https://mediaarea.net/en/MediaInfo) (through `pymediainfo`, [ADR-0012](../../adr/0012-mediainfo-through-pymediainfo.md)) off the GUI thread; where libmediainfo cannot be loaded, every video item is refused with a message to install it. With a TMDb key in Settings, the item is identified (an id in its name or `.nfo`, else a title search) and the release name carries TMDb's French title, the synopsis goes in the description, the Draft carries `tmdbData`, and the releases c411 already has are looked up by TMDb id. Refusals: archives, containers other than MKV, MP4, M4V, AVI, TS, M2TS or a disc (ISO, BDMV, VIDEO_TS), GPU encoders (NVENC, QSV, AMF), an encode under c411's minimum bitrate (not a WEB-DL or a remux), banned teams (Wawacity, kORE, RARBG…), no French audio and no full French subtitles, and a pack whose files differ in specs or team. Warnings: the French title, forbidden sources, WEB needing its VOD platform in the description, the MICKEY detag, missing episodes of a season, and the 28-slot duplicate rule (not computed: see the existing releases). The name follows c411's templates, from the file name and MediaInfo: `Le.Film.2020.VFF.1080p.BluRay.AC3.5.1.x264-TFA` (language, resolution, source, REMUX/BDMV/ISO, HDR, audio, video codec; `x264`/`x265` for encodes, `H264`/`H265` for a WEB-DL, `AVC`/`HEVC` for remuxes and discs; the team tag kept with its special characters dropped, `NOTAG` when none). The one video file of a folder is named exactly the release title inside the torrent. The NFO is MediaInfo's full text of each file (the first one only for a pack of more than ten), also sent as the Draft's `mediainfo`, and the language, quality, source and codec options are pre-filled where c411's values name them.

## GPS

For **GPS** (Applications, Cartes, Divers) and **Emulation** (Émulateur, ROM/ISO), which no Content Kind proposes (pick the category in the form), the release name keeps spaces and accents where c411 allows them. GPS refuses an empty item, archives (RAR/ZIP/7z; install `.cab` and text files are fine) and downloader executables, warns that the version and activation must be stated and that alpha or early-access versions are banned, and suggests `Marque.Zone.Année.Support` (the support is the system its files run on). Emulation refuses archives unless the pack holds more than 50 files, a password-protected zip in such a pack (detected for zip only), a `.bin` without a `.cue` and a CloneCD image without its `.ccd`, `.img` and `.sub`; it warns about retro platforms only and about machines mixed in a pack (except MAME), and names a game `[SNES]Zelda [EU - MULTI] SFC` (console from the ROM extension, region and languages from the `(Europe) (Fr,En)` tags). Both have an NFO with the facts, a place for the install instructions in French, and every file listed.

## Applications

For **Applications** (Autre, Formation, Linux, MacOS, Smartphone, Tablette, Windows), which no Content Kind proposes, the subcategory defaults from the files (`.exe`/`.msi` Windows, `.dmg`/`.pkg`/`.app` MacOS, `.deb`/`.rpm`/`.AppImage` Linux, `.apk`/`.ipa` Smartphone, else Autre) and the **release type** (keygen, crack, patch, installer or portable) is decided from the files and shown as a note you can override by editing the name. The decision table is TorrentLinker's own reading of c411's rules and is **not verified** against c411's wiki page (see [the rules summary](../../research/upload-rules.md)). Refusals: archives (install `.cab` and text files are fine) and downloader executables. Warnings: the install note (not for a portable release), no alpha or early access, no IPTV software, an older version of the same generation is removed. The name is `Nom Version [OS Langue Type]` (`[OS] Nom Version Langue [EXT]` for a phone or tablet), and the NFO and description state the version, system, year, size, languages, activation and requirements, with a place for the install instructions in French.

## Games

For **Jeux Vidéo** (Autre, Linux, MacOS, Microsoft, Nintendo, Smartphone, Sony, Tablette, Windows, VR), proposed for the *game* kind, the subcategory defaults from the files (`.nsp`/`.xci` Nintendo, `.pkg` Sony, `.xex` Microsoft, `.apk` Smartphone, `.dmg` MacOS, `.AppImage` Linux, `.exe` Windows, VR when the name says so). For a PC game the **release type** (scene, repack, portable, GOG, DRM-free, preactivated) is decided from the files (crack files, `.iso`, `setup.exe` with `.bin` data, `steam_api`, GOG in the `.nfo`) and shown as a note; the decision table is TorrentLinker's own reading of c411's rules and is **not verified** against c411's wiki page ([rules summary](../../research/upload-rules.md)). Refusals: archives (except console packs, one archive per game), downloader executables, and for a console, files outside its accepted containers. Warnings: one scene release plus one repack, one repacker release and one portable per scene release, one GOG version, one version per console game, the region (PAL/EU, NTSC/US, NTSC-J/JP, HK). Names keep spaces and accents: scene and repack names as they are, portable `Nom - 1.2 [Windows - FR - PORTABLE]`, GOG `Nom (4.04) [MULTI - Windows][GOG]`, VR prefixed `[VR]`, console `[Switch]Zelda [EU - FR] NSP` (PS4 and PS5 add `-CUSA…` or `-PPSA…`). A scene release's own `.nfo` is sent as the NFO (decoded from the DOS code page, so its bytes are not strictly unaltered); otherwise the NFO states the version, system, year, size, languages, region, crack or loader and requirements, with room for the install instructions in French. The language option is pre-filled from the name.
