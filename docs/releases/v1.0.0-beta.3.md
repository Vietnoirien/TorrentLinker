# TorrentLinker 1.0.0-beta.3

Cette bêta corrige l’actualisation des dossiers et la présentation du lecteur vidéo.

- Après une analyse réussie, les fichiers déplacés ou supprimés quittent la liste des médias. Un dossier inaccessible conserve son inventaire pour éviter de confondre un disque déconnecté avec des fichiers supprimés.
- Le plein écran du lecteur ne conserve plus de marge extérieure.
- La hauteur de la vidéo suit la fenêtre, sans l’ancien plafond de 520 pixels.
- Une flèche de retour ferme la lecture. Changer de section média ferme aussi la vidéo ; la barre musicale reste indépendante.

Validation : 22 tests médias passent, ainsi qu’un contrôle supplémentaire du bouton de retour. Les contrôles de style et de types passent.

Cette version reste une préversion de la future 1.0. La version stable reste 0.12.2 ; les mises à jour entre bêtas sont manuelles. Les limites de codecs et de pistes du navigateur décrites dans la bêta précédente restent applicables.
