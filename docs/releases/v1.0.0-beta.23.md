# TorrentLinker 1.0.0-beta.23

L'onglet **Profil** devient le premier onglet Zen sur le bureau et le WebUI. Cette
version apporte aussi les contrôles du Plan au WebUI, affiche sa version dans le
titre du navigateur et corrige un problème de démarrage de l'AppImage avec des
pilotes Mesa récents.

## Profil et extension navigateur

- Le profil API affiche le compte, la date d'inscription, la Classe, le niveau,
  les quêtes, le Solde Zen, les transferts et l'autorisation de télécharger.
- L'extension facultative ajoute les seeds actifs, les uploads validés, la durée
  totale de seed et les statistiques de transfert choisies. Les données sont lues,
  prévisualisées puis envoyées manuellement depuis votre session c411.
- L'association exige le même compte que l'API. Les données indiquent leur source
  et leur dernière synchronisation ; après cinq minutes, elles sont signalées
  comme anciennes. **Déconnecter et effacer** révoque l'accès et supprime l'aperçu
  enregistré. Les données de l'extension ne modifient pas les réglages du Plan.
- Les cookies de connexion et les clés API restent hors des aperçus. Les codes
  d'association durent 10 minutes et les connexions une heure. Une connexion
  expirée peut être remplacée depuis l'extension.

### Installer dans Brave, Chrome ou Edge

Téléchargez **TorrentLinker-companion.zip** ci-dessous et extrayez-le. Dans Brave,
ouvrez `brave://extensions`, activez **Mode développeur**, puis cliquez sur
**Charger l'extension non empaquetée**. Sélectionnez le dossier extrait
`torrentlinker-companion`, qui contient `manifest.json`. Le ZIP lui-même ne se
sélectionne pas dans ce dialogue. Chrome et Edge proposent le même parcours sur
leur page Extensions.

Désactivez l'ancien prototype si vous l'aviez installé. Dans TorrentLinker,
ouvrez **Zen → Profil → Connecter l'extension**, puis suivez les étapes affichées.
Le récepteur bureau est local à cet ordinateur. Un WebUI distant nécessite HTTPS.
L'extension est également disponible depuis l'onglet Profil.

## Plan dans le WebUI

Le WebUI reprend les contrôles du planificateur bureau : budgets, limites de
torrents, catégories, remises en seed, espace réservé, estimations de durée,
dossiers par catégorie et sélection des clients. Il permet d'examiner et de trier
la proposition, de confirmer l'envoi et d'arrêter les opérations en cours.

## Corrections et documentation

- La version de TorrentLinker apparaît dans le titre du WebUI et de sa documentation.
- L'AppImage utilise les bibliothèques système `libstdc++` et `libgcc_s` afin de
  ne pas masquer les versions requises par les pilotes Mesa/LLVM du système.
- Les guides français et anglais expliquent le Profil, l'association de
  l'extension et les contrôles du Plan.

## Installation

Les téléchargements comprennent Linux x86_64, Windows, macOS Apple Silicon et
l'extension navigateur. Pour Docker :

```sh
TL_IMAGE_TAG=1.0.0-beta.23 docker compose up -d --pull always
```

L'image `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.23` et le tag `beta`
ciblent cette préversion, pour amd64 et arm64. Le tag stable `latest` reste inchangé.

## English

**Profile** is now the first Zen tab on desktop and WebUI. It shows API account
data, progression, Zen balance, transfers and download eligibility. The optional
browser companion adds selected advanced statistics through manual preview and
send. Pairing requires the same API account; snapshots show their source, sync
time and stale status. Disconnect clears saved companion data. Snapshots never
change planning inputs, and do not contain login cookies or API keys.

To install the companion, extract **TorrentLinker-companion.zip**, open
`brave://extensions` in Brave, enable **Developer mode**, and choose **Load unpacked**.
Select the extracted `torrentlinker-companion` folder containing `manifest.json`.
Chrome and Edge use the same Extensions workflow. Disable the old prototype,
then open **Zen → Profile → Connect companion** in TorrentLinker. Remote WebUI
connections require HTTPS. Pairing codes last 10 minutes and connections one hour.

The WebUI now includes the desktop planner's budget, torrent limits, categories,
reseed, storage, timing, destination and client controls, with proposal review,
sorting, confirmed sending and cancellation. The browser title shows the app
version. Linux AppImages use host compiler runtimes to avoid conflicts with newer
Mesa drivers. French and English guides cover the new workflows.

This is a prerelease. The stable release remains 0.12.2.
