TorrentLinker 0.10.6 actualise la file de téléchargement quand l’Assistant ou un autre client y ajoute ou modifie des éléments.

## File de téléchargement

- La file se met à jour automatiquement dans la recherche sur ordinateur et dans l’interface web, y compris après une modification faite par l’Assistant.
- La sélection reste en place lors de l’actualisation, et chaque file reste associée au client choisi.
- L’outil `enqueue` confirme que les éléments sont enregistrés dans `TorrentLinker > Recherche > File de téléchargement`. Il ne les envoie pas au client torrent et ne démarre aucun téléchargement. Utilisez l’envoi de la file pour démarrer les téléchargements lorsque vous le souhaitez.

## Téléchargements

- Windows : `TorrentLinker.exe`
- Linux : `TorrentLinker-x86_64.AppImage`
