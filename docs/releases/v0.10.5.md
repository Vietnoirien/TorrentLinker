TorrentLinker 0.10.5 permet de configurer un dossier de téléchargement manquant directement depuis une discussion avec l’Assistant.

## Configuration guidée dans le chat

- Si le dossier manque, l’Assistant demande son emplacement pour le client et la catégorie concernés, avec des suggestions vérifiées et une réponse libre.
- Une carte présente le client, la catégorie, le chemin local et le chemin vu par le client. La modification nécessite votre approbation explicite.
- Après validation et enregistrement des paramètres, la tâche initiale reprend sans répéter les actions déjà terminées et conserve ses permissions habituelles.
- Un refus ne change pas les paramètres. Un chemin invalide permet de corriger la réponse. L’attente est conservée après redémarrage.

## Clients et catégories

- Prise en charge des dossiers par catégorie dans la file de téléchargement, les Plans et les contrôles de budget.
- Synchronisation des modifications approuvées avec les paramètres de l’application sur ordinateur.
- Nouveaux outils MCP pour consulter les dossiers proposés et demander une configuration ciblée.
- Guides français et anglais actualisés.

Pour un client distant, les correspondances de chemins doivent déjà être vérifiées. Les envois répartis sur plusieurs disques doivent être effectués en lots séparés pour préserver les contrôles d’espace disponible.

## Téléchargements

- Windows : `TorrentLinker.exe`
- Linux : `TorrentLinker-x86_64.AppImage`
