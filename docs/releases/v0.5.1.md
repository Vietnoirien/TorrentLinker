TorrentLinker 0.5.1 fixes c411 upload seeding after publication and improves the Upload form.

## Upload fixes

- New torrents include c411's source tag from the start. Their info-hash now matches the published torrent, so the torrent added to your client before publication can keep seeding afterward. Verified against a real published 3D upload.
- Original files keep their names and locations. TorrentLinker maps the torrent's filenames inside the torrent client and verifies the data before seeding.
- The Image URL is included in the Draft description even after you edit its text. Changing the URL updates the presentation image without resetting your text or removing other images.

## Upload form

- Search Local Items by filename using the new search bar, alongside the Content Kind and Show all filters.
- Open Postimages with **Host image…**, upload your presentation image, then paste its direct link into the Image URL field.
- Updated French translations.

## Existing uploads

The hash fix applies to newly created torrents. Uploads created with older versions may still need c411's published `.torrent` and a filename mapping inside the torrent client. Existing files on disk do not need to be renamed. Drafts already saved on c411 are not rewritten automatically.

## Downloads

- Windows x64: `TorrentLinker.exe`
- Linux x86_64: `TorrentLinker-x86_64.AppImage`
