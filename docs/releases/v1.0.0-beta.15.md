# TorrentLinker 1.0.0-beta.15

La bibliothèque de l'interface web propose maintenant les deux actions groupées de l'application de bureau : « Vérifier tous les Candidats » et « Remettre en seed toutes les correspondances complètes ».

Comme sur bureau, elles utilisent les Candidats trouvés par les recherches précédentes (« Chercher des candidats » sur un élément). Les éléments déjà en seed et les Candidats refusés sont ignorés. La vérification compare chaque Candidat aux fichiers locaux et liste les correspondances complètes. La remise en seed demande confirmation, lance chaque correspondance complète une seule fois et compte les torrents déjà présents dans le client. Les archives et les renommages sur disque restent à traiter élément par élément.

Validation : la suite complète passe (1538 tests), ainsi que les 42 tests web dans Chromium.

Cette version est une préversion. La version stable reste 0.12.2.
