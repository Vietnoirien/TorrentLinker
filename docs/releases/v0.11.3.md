# TorrentLinker 0.11.3

## Correction des demandes de dossier de l'Assistant

- Les outils de modification d'un dossier de téléchargement exigent maintenant
  une catégorie explicite. L'omission de ce champ ne crée plus une proposition
  de dossier par défaut pour toutes les catégories non configurées.
- Cette vérification couvre aussi l'outil générique `propose_action`. L'Assistant
  reçoit une erreur qui lui indique comment retrouver la bonne catégorie.
- Le dossier global reste disponible sur demande explicite, avec `category=null`
  et une approbation qui précise son effet sur toutes les catégories sans dossier.

Les essais avec le modèle local Qwen3.8-27B-MXFP4-off ont vérifié la configuration
d'un dossier Films et un lot Films/Jeux, avec des paramètres temporaires et des
clients torrent simulés. Le dossier global est resté vide dans les deux cas.

Cette version inclut les corrections du Catalogue et la fenêtre de configuration
des dossiers dans la vue Plan introduites en 0.11.2.
