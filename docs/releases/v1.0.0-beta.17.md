# TorrentLinker 1.0.0-beta.17

L'Assistant adopte la présentation du Media Center, sur bureau et dans l'interface web.

- **Un seul champ de saisie** pour la page Assistant et le panneau du Media Center. Le bouton d'envoi devient **Arrêter** pendant une exécution. Sous le champ, le modèle et le mode de la discussion se changent d'un clic.
- **Le mode se change depuis la discussion** : un clic sur « Propositions uniquement » passe en « Exécuter dans les limites ». La première fois, une confirmation explique ce que ce mode autorise.
- **En-tête de discussion** avec son titre et un menu ⋯ : paramètres, renommer, déplacer, supprimer. Les gros boutons autour de la liste disparaissent.
- **Liste des discussions** avec une recherche, un bouton ＋ et, sur bureau, un clic droit pour renommer, déplacer ou supprimer. Sa largeur est conservée.
- **Exemples de demandes** dans une nouvelle discussion : un clic les copie dans le champ, sans les envoyer.
- **Connexions aux modèles dans Paramètres → Assistant.** L'onglet Connexions de l'Assistant disparaît ; « Connecter un modèle » y mène directement.
- **Automatisations en cartes** avec leur fréquence, leur état et un bouton principal (Exécuter maintenant ou Activer).
- **Historique** : chaque exécution indique sa discussion, sa date et son état.

Les guides de l'Assistant et leurs captures sont mis à jour.

Cette version est une préversion. La version stable reste 0.12.2.
