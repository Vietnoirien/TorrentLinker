TorrentLinker 0.5.2 improves update detection and fixes a misleading c411 download error.

## Update notifications

- Check for new stable releases at startup and every 30 minutes while the app is running. Successful checks are cached for 30 minutes instead of a day.
- Compare releases with the version the running window started with, so installing a newer version on disk does not hide its update notice.
- The notice links to the release page. Downloading and installing updates remains manual.

## c411 download errors

- When c411 explicitly returns "Torrent not available for download", show that reason instead of incorrectly reporting a rejected API key.
- Record the unavailable torrent as failed and continue sending the rest of the Plan. Genuine authentication failures still stop the operation.

This fixes the error message and Plan handling. It does not make a torrent that c411 refuses available for download.

## Downloads

- Windows x64: `TorrentLinker.exe`
- Linux x86_64: `TorrentLinker-x86_64.AppImage`

Older versions keep their previous update-check schedule until you install this release.
