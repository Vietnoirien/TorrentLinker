# TorrentLinker 1.0.0-beta.47

## Media: films on the tracker

- With a c411 key, Home and Films add two rows, for films only. **Available on the tracker**, right after your recent additions, shows c411's latest film releases your library does not have, newest first. Each refresh reads the latest 200 releases in two requests.
- **Better versions on the tracker**, the last row, shows films you have with a Catalogue release scoring at least 5 points more than your file. It costs no request: your file gives the film's duration, the Catalogue every release's name and size. It is worked out again daily.
- Both rows score releases with your active ReleaseScore profile when shown, so a new profile or threshold changes them at once.
- A tracker film's panel shows its release, score, size, sources and publication date. **Add to download queue** queues it like Search does; nothing starts until you send the queue. The release's category needs a Download Folder.
- In Horizon's Home, both rows are categories of its menu.

## Settings

- ReleaseScore has its own section. Its new **Media suggests releases from** field sets the score the tracker rows require (90 by default).

## Installation

- Windows, Linux AppImage, macOS Apple Silicon, browser companion and Docker distributions are provided by this release.
- Restart an existing desktop or server installation after updating. For Docker, use `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.47`, or update the `beta` tag.

This is a beta release. Series and season packs are not suggested yet: ReleaseScore cannot score a pack without each episode's runtime.
