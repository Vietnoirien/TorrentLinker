TorrentLinker 0.9.2 corrige l'ouverture de l'accès des agents MCP dans l'application Windows.

## Correctif Windows

Cliquer sur **Ouvrir l'accès des agents MCP** pouvait afficher une erreur `ValueError`, accompagnée d'un message invitant à vérifier si le port 8790 était déjà utilisé.

Le problème venait de l'initialisation du journal du serveur MCP : elle tentait d'utiliser une console, absente dans l'exécutable Windows. Le serveur utilise désormais le journal de l'application et démarre sans console.

- Les erreurs de démarrage affichent leur raison et sont enregistrées dans `torrentlinker.log`.
- Le message concernant une autre instance ou application apparaît uniquement lorsque l'adresse est déjà utilisée.
- Le journal de l'application fonctionne aussi sans sortie console.

Si vous avez rencontré cette erreur avec la version 0.9.0 ou 0.9.1, fermez TorrentLinker, remplacez l'exécutable par celui de cette version, puis ouvrez de nouveau l'accès des agents dans les Paramètres.

## Validation

Les tests de démarrage des applications distribuées vérifient désormais le lancement du serveur MCP et la découverte de ses outils avec authentification. La validation locale comprend 1 025 tests réussis, le démarrage sans console, les conflits de port et une nouvelle tentative après libération du port.

- Windows x64 : `TorrentLinker.exe`
- Linux x86_64 : `TorrentLinker-x86_64.AppImage`
