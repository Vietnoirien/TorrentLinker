# TorrentLinker 1.0.0-beta.11

L'accueil vidéo du Media Center s'organise désormais en rangées, sur bureau comme dans l'interface web : récemment ajoutés, les principaux genres de votre bibliothèque, séries, les mieux notés et pas encore vus. Chaque rangée défile horizontalement et propose « Voir tout », qui ouvre la grille avec le filtre correspondant. « Accueil » ramène aux rangées.

La présentation du film sélectionné affiche son affiche à gauche du titre et du synopsis. Le filtre par genre retrouve maintenant un film même quand il a plusieurs genres.

Les boutons du Media Center et de sa discussion suivent un style commun : une action principale, des boutons secondaires, des actions discrètes et des icônes avec info-bulle. Dans l'interface web, le mode Media Center devient une icône et la barre d'outils gagne l'icône de discussion.

Dans l'interface web, la durée des films affiche les heures (2:13:54).

Validation : la suite complète passe (1531 tests). Les tests web dans Chromium couvrent les rangées, « Voir tout » et la discussion.

Cette version est une préversion. La version stable reste 0.12.2.
