# TorrentLinker 1.0.0-beta.25

Cette version corrige le repartage depuis la bibliothèque et la recherche des
dossiers de saisons.

## Repartage et séries

- Un torrent déjà présent dans le client affiche un message explicite, avec son
  état et son emplacement lorsqu'ils sont disponibles, au lieu d'un échec qui
  n'affichait que son nom. Le torrent existant reste inchangé.
- Le repartage refuse les renommages dont le chemin source est déjà occupé.
  Cela évite qu'une permutation de noms déplace les fichiers de la bibliothèque,
  même si l'ajout du torrent est ensuite annulé.
- Un dossier nommé `Saison 2` ou `Season 2` retrouve le titre de la série à partir
  des noms cohérents des épisodes, ou du dossier parent si les épisodes n'ont pas
  de titre de série. Le numéro de saison est conservé.
- Une préparation de repartage qui expire nettoie son suivi de vérification
  lorsque le retrait du torrent réussit. Si le retrait échoue, le suivi est
  conservé pour permettre le nettoyage ultérieur.

La recherche automatique d'une saison dans un dossier contenant toute une série
reste soumise au filtre de taille. Utilisez la vérification manuelle d'un candidat,
la recherche de torrents compatibles ou une profondeur qui sélectionne les saisons.

## Validation et problèmes connus

Les 1 944 tests ont été exécutés : 1 925 réussites, 19 échecs, aucun test ignoré.
Les intégrations avec qBittorrent, Deluge, Transmission et µTorrent Classic ont
réussi. Les échecs concernent 16 contrôles de l'assistant avec le modèle local
et trois tests navigateur : deux scénarios de cartes de brouillons avec une
page de test incomplète, et un panneau Zen restant masqué dans le parcours de
configuration. Un blocage Qt a interrompu l'exécution groupée ; les 13 tests du
lecteur natif ont ensuite réussi séparément. La cause de ce blocage reste à établir.

## English

This release fixes Library reseeding and searches from season folders.

- Torrents already present in the client show an explicit notice, including
  available state and location, instead of a filename-only failure. The existing
  torrent is left unchanged.
- Reseeding refuses renames whose source path is already occupied. This prevents
  filename swaps from moving Library files, including when setup later fails.
- Generic folders such as `Season 2` infer the show title from consistent episode
  names, or from the parent folder when episode names lack a show title. The
  season number is preserved.
- Timed-out reseed setup clears its Verification record after successful torrent
  removal. Failed removal keeps the record available for later cleanup.

Automatic season discovery inside a whole-series folder still uses the size
filter. Use manual candidate checking, compatible-torrent discovery, or a Library
depth that selects individual seasons.

All 1,944 tests ran: 1,925 passed, 19 failed, none skipped. qBittorrent, Deluge,
Transmission and µTorrent Classic integrations passed. The failures comprise 16
local-model assistant checks and three browser checks: two upload-draft card
scenarios with an incomplete test page, and a hidden Zen panel in guided setup.
A Qt deadlock interrupted the combined run; all 13 native-player tests passed
separately afterward. The cause of the combined-run hang remains undiagnosed.

This is a prerelease. The stable release remains 0.12.2.
