# TorrentLinker 1.0.0-beta.16

TorrentLinker est maintenant disponible sur macOS et en image Docker.

- **macOS** : `TorrentLinker-macOS-arm64.dmg` pour les Mac Apple Silicon. L'application n'est pas notariée : au premier lancement, faites un clic droit sur l'application puis **Ouvrir**.
- **Docker** : l'interface web est publiée sur `ghcr.io/vietnoirien/torrentlinker` pour amd64 et arm64, avec les tags `beta`, `latest` et le numéro de version. Un exemple Compose autonome (`deploy/compose.example.yaml`) démarre le serveur sans les sources. Le guide Docker décrit les tags et la mise à jour.
- Le README recommande la dernière préversion et renvoie à la liste des tags.

Chaque version n'est publiée que si les tests de démarrage passent sur Windows, Linux, macOS et dans le conteneur.

Cette version est une préversion. La version stable reste 0.12.2.
