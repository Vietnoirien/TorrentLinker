# TorrentLinker 1.0.0-beta.7

Le Media Center sur bureau affiche maintenant les fiches des films en français : titre, synopsis, affiche, genres, réalisation, distribution et note. Elles viennent des descriptions des releases sur c411, avec la clé c411 déjà configurée. Aucune nouvelle clé n'est nécessaire.

Un film téléchargé avec le client torrent est relié à sa propre release. Sinon, la release est cherchée par nom dans le catalogue local. Les fichiers sans correspondance gardent les informations tirées du nom de fichier.

Les fiches sont récupérées après l'actualisation de la bibliothèque, qui n'est jamais bloquée. Chaque réponse est conservée : un film n'est demandé qu'une fois à c411. Si c411 demande d'attendre ou ne répond pas, les fiches restantes sont récupérées à l'actualisation suivante. Les affiches sont téléchargées une seule fois.

La première actualisation demande environ une requête c411 par film.

Validation : la suite complète passe (1523 tests), dont 4 nouveaux tests des fiches de films.

Cette version est une préversion. La version stable reste 0.12.2.
