# TorrentLinker 1.0.0-beta.5

La bibliothèque du Media Center sur bureau charge désormais les cartes suivantes au fil du défilement, sans boutons de pagination. La grille utilise la hauteur de la page, sans la petite zone de défilement intérieure.

La sélection est conservée lors du chargement des cartes suivantes. Changer de filtre réinitialise la liste.

Validation : 8 tests du Media Center sur bureau passent, dont un parcours de 205 éléments. Ruff et le contrôle de types du module modifié passent.

Cette version est une préversion. La version stable reste 0.12.2.
