TorrentLinker 0.5.5 ajoute les estimations dans la file de téléchargement et permet de réduire la fenêtre pour les petits écrans. La documentation est désormais organisée en guides illustrés.

## Petits écrans

- La fenêtre peut être réduite sans être bloquée par la largeur minimale des onglets, y compris avec les libellés français.
- La zone de travail devient défilante lorsque son contenu ne tient plus ; la navigation reste visible et les commandes restent accessibles.
- La taille initiale tient compte de l’espace disponible à l’écran. Le redimensionnement a été testé jusqu’à 800 × 560, en français et en anglais.

## File de téléchargement

- Ajout des colonnes **≈ Zen/jour** et **≈ Note**, avec tri numérique et les mêmes explications que dans les résultats de recherche.
- Les estimations sont recalculées lorsque le Profil Zen ou les torrents en partage changent, ainsi qu’au rechargement de la file, même sans lancer de recherche.
- Les torrents déjà en partage utilisent leur estimation actuelle. Les torrents provenant d’autres indexeurs affichent un tiret.
- Aucun appel API supplémentaire n’est nécessaire pour afficher ces colonnes.

## Documentation

- README français et anglais raccourcis, avec une capture de l’application et les liens essentiels.
- Guides pour la configuration, la Bibliothèque, la recherche, la file, le Zen, les uploads et le dépannage.
- Dix captures de l’interface avec des données d’exemple, sans compte ni fichiers personnels.
- Les règles d’upload par catégorie et les instructions de développement restent disponibles dans des pages dédiées.
