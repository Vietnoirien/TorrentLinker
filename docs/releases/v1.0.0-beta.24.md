# TorrentLinker 1.0.0-beta.24

Les `.torrent` de c411 peuvent désormais être téléchargés avec votre session
navigateur, grâce à l'extension, en plus de la clé API. L'option est désactivée
par défaut.

## Téléchargements par session

- **Paramètres → Extension** (bureau et WebUI) regroupe la connexion de
  l'extension et la case **Télécharger les .torrent avec ma session c411**. Les
  contrôles de connexion quittent l'onglet Profil.
- Option activée : la file d'envoi et l'envoi du Plan demandent les `.torrent`
  au navigateur, 100 à l'avance, quatre requêtes en parallèle. Mesuré sur 590
  fichiers : 391 fichiers par minute, sans refus, contre 30 par minute au plus
  avec la clé API. Aucune limite n'est ajoutée par TorrentLinker ; c411 peut en
  appliquer une, et le débit réel varie.
- Un refus (401, 403) arrête l'envoi avec un message dédié. Une demande d'attente
  (429) est respectée. **Le téléchargement ne bascule jamais sur la clé API.**
- Option désactivée : l'extension ne reçoit aucune tâche et les téléchargements
  utilisent la clé API comme avant. Se déconnecter désactive l'option.
- Votre session reste dans le navigateur. Chaque `.torrent` est vérifié (compte,
  empreinte, taille) et conservé en mémoire seulement jusqu'à son envoi.

**Mettez à jour l'extension** : extrayez la nouvelle
**TorrentLinker-companion.zip**, rechargez-la dans `brave://extensions` (ou la page
Extensions de Chrome/Edge), puis reconnectez-la si nécessaire. Firefox n'est pas
encore pris en charge.

## English

c411 `.torrent` files can now be downloaded through your signed-in browser
session using the companion, instead of the API key. It is off by default.

- **Settings → Companion** (desktop and WebUI) holds the companion connection and
  the **Download .torrent files with my c411 session** checkbox; the connection
  controls leave the Profile tab.
- When on, the send queue and Plan sends request torrents from the browser 100
  ahead, four in parallel. Measured on 590 files: 391 files/min with no refusal,
  against at most 30/min with the API key. TorrentLinker adds no cap of its own;
  c411 may apply one, and real speed varies.
- A refusal (401, 403) stops the send with its own message; a wait request (429)
  is honoured. **It never falls back to the API key.**
- When off, the companion receives no work and downloads use the API key as
  before. Disconnecting turns the option off.
- Your session stays in the browser. Each `.torrent` is checked (account, info
  hash, size) and kept in memory only until it is sent.

**Update the companion**: extract the new **TorrentLinker-companion.zip**, reload
it on your browser's Extensions page, and reconnect if asked. Firefox is not
supported yet.

This is a prerelease. The stable release remains 0.12.2.
