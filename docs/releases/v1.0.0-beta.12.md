# TorrentLinker 1.0.0-beta.12

Les séries ont leur propre présentation dans le Media Center, sur bureau comme dans l'interface web. La vue Séries affiche une carte par série, avec son nombre d'épisodes. Choisir une série affiche ses saisons et une rangée de cartes d'épisodes, avec leur durée et le point de reprise. Lancer un épisode enchaîne les suivants dans l'ordre.

Les films ne sont plus pris pour des séries. Un fichier n'est un épisode que si son nom l'indique clairement (S01E02, 1x02, « Saison 2 ») ou s'il se trouve dans un dossier de saison. « Star Wars Episode 4 », un « 1080 » ou une année dans le nom ne suffisent plus. Ces films retrouvent un titre complet après la prochaine actualisation.

Les séries récupèrent aussi leur fiche c411, y compris depuis une intégrale. Les étiquettes intégrées aux fichiers (série, saison, épisode, synopsis) sont lues quand elles existent.

Les vues Films et Séries s'organisent en rangées, comme l'accueil : récemment ajoutés puis les principaux genres, avec « Voir tout » pour la grille complète.

Un bouton ⟳ dans la barre d'outils du Media Center actualise la médiathèque ; pendant l'actualisation, le même bouton l'annule. Sur bureau, la médiathèque s'actualise une fois à la première ouverture du Media Center après le démarrage.

Les autres pages de l'application suivent maintenant le style de boutons commun : une action principale par zone, des actions secondaires discrètes et des icônes avec info-bulle.

Validation : la suite complète passe (1534 tests). Les 40 tests web dans Chromium passent.

Cette version est une préversion. La version stable reste 0.12.2.
