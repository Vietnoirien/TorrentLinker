# TorrentLinker 1.0.0-beta.9

Le lecteur vidéo du Media Center sur bureau affiche les heures dans la durée : 2:13:54 au lieu de 133:54.

Les sous-titres suivent la taille de l'image, en fenêtre comme en plein écran. Les sous-titres sur plusieurs lignes ne sont plus coupés. Un sous-titre très long est réduit plutôt que de sortir de l'image.

Validation : les tests du Media Center passent, dont des contrôles sur deux lignes, trois lignes, une ligne longue et le retour du plein écran.

Cette version est une préversion. La version stable reste 0.12.2.
