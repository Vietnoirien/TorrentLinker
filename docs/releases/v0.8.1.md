TorrentLinker 0.8.1 corrige le regroupement du tracker miroir de c411 dans la gestion des torrents.

- Dans l'arborescence de l'application de bureau, `c411.org` et `tk.c411.tw` apparaissent désormais dans une seule branche **c411.org**.
- Les torrents qui utilisent uniquement le miroir sont inclus. Un torrent présent sur les deux adresses ne compte qu'une fois dans la branche et ses catégories.
- Le filtre de tracker de l'interface web regroupe également les deux adresses.
- Les détails conservent les véritables noms des serveurs d'annonce. Les autres trackers restent séparés et aucune adresse n'est modifiée dans votre client torrent.

## Téléchargements

- Windows x64 : `TorrentLinker.exe`
- Linux x86_64 : `TorrentLinker-x86_64.AppImage`
