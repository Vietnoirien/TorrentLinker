# TorrentLinker 1.0.0-beta.14

Dans le Media Center, la barre du lecteur de musique ne reste plus affichée dans la partie Vidéo quand la musique est en pause. Si la musique joue en arrière-plan, la barre reste visible pour pouvoir la mettre en pause. En pause, elle disparaît jusqu'au retour dans Musique ou à la reprise de la lecture.

Dans l'interface web, lancer un film après une musique mise en pause affiche de nouveau le lecteur.

Validation : la suite complète passe (1535 tests), ainsi que les 42 tests web dans Chromium.

Cette version est une préversion. La version stable reste 0.12.2.
