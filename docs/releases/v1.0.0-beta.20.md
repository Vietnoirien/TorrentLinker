# TorrentLinker 1.0.0-beta.20

L'onglet Torrents se rapproche de qBittorrent, sur bureau et dans l'interface web.

- **Barre d'outils compacte** : une seule rangée d'icônes (démarrer, pause, revérifier, retirer, actualiser) avec le champ de recherche à droite, à la place des gros boutons.
- **Barre latérale** : sections Statut et Tags avec leurs totaux au-dessus des trackers (sur le web : Statut, Catégories, Tags, Trackers).
- **Barre de progression** remplie de gauche à droite (elle se remplissait de bas en haut sur bureau).
- **Interface web alignée sur le bureau** : mêmes colonnes dans le même ordre, sélection des lignes par clic (Ctrl pour ajouter, Maj pour une plage), actions grisées sans sélection, et un panneau Informations / Fichiers / Activité sous le tableau. États et libellés traduits.
- **Tous les clients** : un test vérifie que qBittorrent, Deluge, Transmission, µTorrent et BitTorrent Classic remontent les mêmes informations (taille, état, trackers, débits, ratio, ETA, pairs). qBittorrent liste désormais tous les trackers d'un torrent demandé seul.

Cette version est une préversion. La version stable reste 0.12.2.
