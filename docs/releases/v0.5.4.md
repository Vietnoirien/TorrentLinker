TorrentLinker 0.5.4 améliore le premier démarrage, la Bibliothèque et le suivi Zen. La documentation principale est désormais en français.

## Premier démarrage

- Sans clé API configurée, un message de bienvenue vous guide vers les Paramètres au lieu de déclencher des erreurs de connexion.
- Le chargement des données démarre après l’enregistrement de la clé. Si vous annulez ou laissez la clé vide, l’application attend et conserve un lien vers les Paramètres.

## Bibliothèque

- Le bouton **Ajouter un dossier…** permet de choisir un dossier, son type de contenu et sa profondeur d’analyse directement depuis la Bibliothèque. Après enregistrement, l’analyse démarre et la liste affiche ce dossier.
- Les dossiers déjà présents sont détectés pour éviter les doublons.
- **Reseeder toutes les correspondances complètes** distingue désormais les nouveaux reseeds des torrents déjà présents dans le client. Le bilan n’annonce plus une vérification en cours lorsque rien n’a été ajouté. Les nouvelles correspondances continuent d’être traitées même si d’autres torrents sont déjà présents.

## Zen

- La vue des torrents en partage affiche leur **Note estimée**, avec tri numérique.
- Chaque catégorie et sous-catégorie affiche la moyenne des notes de ses torrents, sous-catégories comprises. Les notes indisponibles sont exclues du calcul.
- Ces notes restent des estimations selon votre classe, la catégorie, le nombre de seeders et l’ancienneté du partage.

## Documentation

Le README principal est maintenant en français. Une version anglaise reste disponible via le lien en tête du document. Les nouveaux messages de l’interface sont également traduits en français.

## Téléchargements

- Windows x64 : `TorrentLinker.exe`
- Linux x86_64 : `TorrentLinker-x86_64.AppImage`
