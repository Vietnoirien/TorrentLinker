# TorrentLinker 1.0.0-beta.10

La discussion du Media Center est désormais un panneau compact, sur bureau comme dans l'interface web. Il ne montre qu'une discussion. L'en-tête propose ☰ pour vos discussions média et « Nouvelle discussion », ⋯ pour les paramètres et la suppression, et ✕ pour fermer. Un seul bouton rond envoie le message, puis devient « Arrêter » pendant que l'assistant travaille.

Les dossiers, les automatisations, l'historique et les connexions restent dans la page Assistant.

Le bouton qui ouvre la discussion la ferme aussi. La largeur du panneau se règle en faisant glisser son bord. Elle est conservée après un redémarrage sur bureau, et après un rechargement de la page sur le web. Le panneau se redimensionne aussi quand la fenêtre n'est pas en plein écran.

Le texte de la discussion se réorganise quand le panneau se rétrécit : les lignes d'activité des outils trop longues sont abrégées, avec le texte complet au survol.

Validation : la suite complète passe (1525 tests). Les tests web dans Chromium couvrent le panneau compact, le redimensionnement, la largeur conservée et la fermeture par le même bouton.

Cette version est une préversion. La version stable reste 0.12.2.
