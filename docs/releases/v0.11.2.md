# TorrentLinker 0.11.2

## Dossiers de téléchargement

- Les téléchargements demandés à l'Assistant dans plusieurs catégories utilisent
  le dossier de chaque torrent. Une catégorie sans dossier déclenche une demande
  ciblée, sans affecter toutes les autres catégories non configurées.
- La validation de l'espace disponible tient compte de chaque disque utilisé par
  un lot de téléchargements.
- Les demandes de configuration d'un dossier par défaut indiquent clairement
  qu'il s'applique à toutes les catégories sans dossier spécifique.

## Plans et Catalogue

- Lorsqu'un dossier manque, la vue Plan affiche une fenêtre pour le configurer
  pour la catégorie et le client concernés. Annuler ferme la fenêtre sans lancer
  de Plan. Aucun bouton supplémentaire n'est ajouté à la vue.
- Le Catalogue récupère les catégories XXX, dont Images, via Torznab lorsque
  l'API JSON de c411 les omet. Les anciens états de synchronisation vides sont
  repris automatiquement, avec les limites de pagination habituelles.
