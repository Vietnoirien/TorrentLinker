# TorrentLinker 1.0.0-beta.4

Cette bêta corrige le retour à la bibliothèque depuis le lecteur vidéo.

- La flèche de retour ferme réellement la vidéo et réaffiche la navigation, au lieu de laisser un lecteur noir.
- Changer de section, notamment vers Musique, ferme aussi la vidéo.
- La position de lecture et la file sont conservées. Une nouvelle lecture reste possible après le retour.

Validation : 22 tests médias passent, dont le retour depuis le plein écran, le changement de section et la reprise d’une lecture. Ruff et le contrôle de types du module modifié passent.

Cette version reste une préversion de la future 1.0. La version stable reste 0.12.2.
