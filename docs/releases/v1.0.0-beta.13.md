# TorrentLinker 1.0.0-beta.13

Ajouter un client Transmission depuis l'interface web affichait « Impossible de se connecter » alors que la connexion fonctionnait (#41). La vraie cause était l'option de Transmission « Ajouter .part aux noms des fichiers incomplets », activée par défaut, que TorrentLinker refuse : elle renommerait vos propres fichiers pendant une remise en seed.

L'interface web affiche maintenant cette raison et propose de désactiver l'option dans Transmission puis de réessayer, comme l'application de bureau.

Validation : la suite complète passe (1535 tests), ainsi que les 42 tests web dans Chromium, dont un nouveau test du formulaire.

Cette version est une préversion. La version stable reste 0.12.2.
