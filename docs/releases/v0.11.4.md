# TorrentLinker 0.11.4

## Sélections précises pour l'Assistant et MCP

- `catalogue_categories` fournit les catégories de l'Indexer, leurs identifiants
  et le nombre d'entrées en cache.
- `select_catalogue` filtre tout le Catalogue local par catégorie, titre, taille
  et nombre de sources. Il trie par taille, sources, titre ou date d'observation
  dans le cache, dans les deux sens, avec un nombre et un décalage configurables.
- Le résumé calcule le poids exact en octets, le nombre d'entrées sélectionnées,
  les tailles minimale et maximale et le manque éventuel. Ces valeurs portent
  sur toute la sélection, indépendamment de la page affichée.
- `enqueue_selection` met les entrées sélectionnées en file sans recopier leurs
  hashes. `send_selection` démarre uniquement ces entrées déjà en file lorsque
  l'utilisateur le demande. Les droits, approbations, dossiers et budgets habituels
  restent applicables ; une sélection modifiée doit être examinée à nouveau.

Ces outils sont disponibles dans l'Assistant intégré et sur le serveur MCP partagé,
y compris via le pont stdio. Les résultats sont exacts pour les métadonnées en cache,
sans garantie de couverture complète du tracker. Aucun dossier n'est requis pour
une simple consultation du Catalogue.

## Objectifs et torrents du client

- Les objectifs acceptent une catégorie, que la création du Plan conserve.
- La sélection des torrents déjà présents dans le client gagne des filtres par
  titre et plage de taille, ainsi que les classements par plus petite taille,
  meilleure Note et meilleur Zen estimé par Gio.

Le scénario « poids des 500 films les plus légers » a été vérifié avec le modèle
local Qwen3.8-27B-MXFP4-off sur des données isolées, sans téléchargement.
