TorrentLinker 0.10.7 permet de poursuivre l'analyse de la bibliothèque lorsqu'un fichier ou un dossier est inaccessible, notamment après une erreur réseau Windows comme WinError 59.

## Analyse de la bibliothèque

- Les éléments accessibles restent disponibles. Les chemins en erreur apparaissent dans les détails d'une analyse incomplète.
- Les éléments précédemment connus dans les chemins inaccessibles et leur état dans le client torrent sont conservés. Une lecture incomplète ne remplace pas le cache.
- L'interface web signale les analyses partielles et conserve les résultats précédents en cas d'annulation.
- La planification exige une lecture complète des dossiers de téléchargement avant de déterminer quels fichiers sont déjà présents.

Si un chemin est inaccessible, vérifiez l'accès au lecteur ou au partage réseau dans l'Explorateur, puis relancez l'analyse. Le correctif a été testé avec des erreurs de lecture simulées ; il ne modifie aucun fichier de la bibliothèque ni les paramètres réseau.

## Téléchargements

- Windows : `TorrentLinker.exe`
- Linux : `TorrentLinker-x86_64.AppImage`
