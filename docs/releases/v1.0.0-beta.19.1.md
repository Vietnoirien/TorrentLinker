# TorrentLinker 1.0.0-beta.19.1

Correctif d'installation pour le serveur web.

- **Mot de passe par variable d'environnement** : `TL_WEB_PASSWORD` peut maintenant fournir le mot de passe de l'interface web, par exemple depuis une pile Portainer. `TL_WEB_PASSWORD_FILE` reste recommandé et l'emporte si les deux sont définis. Le minimum de 12 caractères s'applique toujours. Merci à vlnc pour la suggestion (#42).

Cette version est une préversion. La version stable reste 0.12.2.
