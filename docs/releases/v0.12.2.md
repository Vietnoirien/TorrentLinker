# TorrentLinker 0.12.2

## Relire les brouillons d'upload dans le chat

- L'assistant peut présenter ses brouillons enregistrés sous forme de cartes, avec leur image, leur catégorie, leur taille et les avertissements de validation.
- Un clic ouvre le détail du brouillon : description, NFO, fichiers et champs d'upload. Le même aperçu est accessible depuis la file des brouillons, sur le bureau et sur le web.
- Chaque aperçu correspond à une révision enregistrée. Si le brouillon change, l'ancienne carte le signale. Consulter un aperçu ne valide ni n'envoie l'upload.
- Ces outils sont également disponibles via MCP.

## Gérer plusieurs clients depuis l'assistant ou MCP

- Sélectionner jusqu'à 10 000 torrents sur plusieurs clients, avec un nombre global ou un nombre par client.
- Comparer leur présence et leur état entre clients, puis affiner et enregistrer la sélection pour les opérations suivantes.
- Les sélections conservent le client et le hash de chaque torrent. Les résultats distinguent les instances sur les clients et les hashes uniques ; un client indisponible reste signalé comme inconnu.
- Mettre en pause, reprendre, revérifier ou supprimer une sélection avec une validation regroupée par client, selon les permissions configurées. La suppression des fichiers affiche les dossiers concernés.
- Le suivi des opérations évite de rejouer les actions déjà réussies ou dont le résultat est incertain. Les comparaisons volumineuses sont paginées.

## Vérification

- Suite complète : 1 337 tests réussis, 109 ignorés. Vérifications ciblées supplémentaires après l'ajout de la pagination.
- Essais avec le modèle local Qwen pour les brouillons d'upload et les sélections multi-clients, dans un environnement isolé sans modification des torrents réels.
