TorrentLinker 0.5.0 adds a Search workspace for finding torrents, comparing them in tabs, and queuing selected downloads. The desktop UI now follows your system theme, with manual light and dark settings.

## Search and torrent previews

- Search c411 with a category/subcategory tree and category-specific filters, including resolution, source, HDR, codecs, languages, profile, season, episode, year and uploader where supported. Other Indexers retain Torznab search.
- Filter available torrents or include **soins palliatifs**, with revival candidates identified in the results.
- Compare sortable **Zen/day** and **Note** estimates based on your Zen Profile. Already seeded torrents use their current seed age; new downloads start at zero seed age with you included in the swarm.
- See publication ages such as **1 hour**, **2 hours** and **3 days**. Hover for the exact local date and time. Sorting uses the original timestamp, and ages refresh while Search is visible.
- Double-click results to open torrent detail tabs with descriptions, centered images, NFO and file previews, plus a link to the website. Opening a preview does not fetch the `.torrent` file.
- Keep multiple torrents open across searches. Reorder and close tabs, use the tab list or keyboard shortcuts, and scroll in either direction when the strip fills up. Search remains accessible.
- Image previews support larger files, scale images for display, and offer retry controls and links when a host is unavailable.

## Download queue

- Add selected results or open torrent tabs to a persistent queue, with a Download Folder for each torrent.
- **Queue all tabs** opens the queue and reports what was added. The queue button stays accessible from torrent details, and validation errors appear above the tabs.
- **Download now** sends one torrent; **Download all tabs** sends the open set. Other queued torrents stay waiting.
- Start, pause, retry, remove entries and clear completed entries. Queues survive restarts and wait for you to start them again.
- Downloads use the existing duplicate, hash and destination-file checks, and respect the Indexer's download limits.

## Desktop and Zen improvements

- Refreshed sidebar navigation, table styling, spacing, filters and empty states. Table columns can be resized and results sorted by their headers.
- **Auto / Light / Dark** theme settings, including improved system dark-mode detection on Linux.
- Zen Seeding groups torrents by category and subcategory. Category counts, filtering and sorting work with the tree.
- Category tags synchronize in qBittorrent and Transmission while preserving personal tags and download folders. Deluge keeps its single label because it carries Verification state.
- c411's alternate announce host is recognized, fixing missing torrents in Seeding and Library matching.
- A dismissible notice links to newer stable GitHub releases. Update checks run at startup and daily; installation remains manual.
- Updated French translations.

## Notes

- Torrent detail tabs last for the current app session; queued downloads persist across restarts.
- Zen/day and Note are estimates. Revival payouts remain separate; this release does not calculate personal revival eligibility or optimize Plans for revival bonuses.
- Clicking a result-column header sorts the current page. Use the search sorting controls to order results across pages.
- Image hosts can still refuse or rate-limit requests; the website link remains available.
